# Project phases

Editable FitBuddy documents follow the seven folders of the supplied [project templates](https://drive.google.com/drive/folders/1laeXjLiMaqP8hnwvammmyUfAwH95jW0O):

1. [Ideation](01-ideation.md): brainstorming/prioritization, problem statement, empathy map.
2. [Requirement analysis](02-requirements.md): solution requirements, stories, journey, data flow and technology stack.
3. [Design](03-design.md): architecture, entities and interface/access design.
4. [Planning](04-planning.md): milestones, dependencies, risks and submission work.
5. [Development](05-development.md): implementation and verification workflow.
6. [Documentation](06-project-documentation.md): abstract, scope, reference alignment and limitations.
7. [Demonstration](07-demonstration.md): recording script and evidence checklist.

Markdown is used so these stay versioned beside the implementation. Institution-specific formatting, member names and real live demonstration evidence must be completed before submission.
